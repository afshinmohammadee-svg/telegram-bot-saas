# معماری سامانه

## اجزا
- پنل وب: React + Vite + TypeScript روی Vercel
- پایگاه داده: Neon PostgreSQL
- احراز هویت پنل: Better Auth؛ ایجاد حساب فقط توسط مدیر کل
- پردازش تلگرام: Cloudflare Worker برای webhook و صف پردازش
- رمزنگاری توکن ربات‌ها: AES-256-GCM در سمت سرور؛ کلید فقط در secret store

## قواعد محصول
- هر حساب کاربری حداکثر یک ربات اختصاصی دارد.
- هر رویداد /start یک بازدیدکننده را ثبت می‌کند.
- گفتگوها و پیام‌ها به مالک همان ربات محدود هستند.
- انقضای اشتراک، پردازش و پاسخ‌گویی ربات را متوقف می‌کند؛ داده‌ها حذف نمی‌شوند.
- اعلان انقضا در فاصله‌های ۷، ۳ و ۱ روز قبل ارسال می‌شود.
- ثبت‌نام عمومی غیرفعال است و فقط مدیر کل حساب ایجاد می‌کند.

## وضعیت پیاده‌سازی
این مخزن در مرحله پایه رابط کاربری است. اتصال واقعی احراز هویت، API، webhook، صف و چرخه اشتراک هنوز باید پیاده‌سازی و آزمون شود. رابط کاربری در حالت خالی نمایش داده می‌شود و داده ساختگی ندارد.
