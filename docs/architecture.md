# معماری سامانه

## اجزا
- پنل وب: React + Vite + TypeScript روی Vercel
- پایگاه داده: Neon PostgreSQL
- احراز هویت پنل: Better Auth؛ ایجاد حساب فقط توسط مدیر کل
- پردازش تلگرام: Cloudflare Worker برای webhook و صف پردازش
- رمزنگاری توکن ربات‌ها: AES-256-GCM در سمت سرور؛ کلید فقط در secret store

## قواعد محصول
- هر حساب کاربری حداکثر یک ربات اختصاصی دارد.
- هر رویداد /start یک بازدیدکننده را ثبت می‌کند.
- گفتگوها و پیام‌ها به مالک همان ربات محدود هستند.
- انقضای اشتراک، پردازش و پاسخ‌گویی ربات را متوقف می‌کند؛ داده‌ها حذف نمی‌شوند.
- اعلان انقضا در فاصله‌های ۷، ۳ و ۱ روز قبل ارسال می‌شود.
- ثبت‌نام عمومی غیرفعال است و فقط مدیر کل حساب ایجاد می‌کند.

## وضعیت پیاده‌سازی
این مخزن در مرحله پایه رابط کاربری است. اتصال واقعی احراز هویت، API، webhook، صف و چرخه اشتراک هنوز باید پیاده‌سازی و آزمون شود. رابط کاربری در حالت خالی نمایش داده می‌شود و داده ساختگی ندارد.

## احراز هویت (پیاده‌سازی اولیه)

- سرور Better Auth روی Vercel Functions در مسیر `/api/auth/*` اجرا می‌شود.
- پایگاه داده از همان جدول‌های `user`, `session`, `account`, و `verification` استفاده می‌کند؛ نام ستون‌های snake_case به‌صورت صریح map شده‌اند.
- ثبت‌نام ایمیل/رمز عبور عمومی با `disableSignUp` غیرفعال است.
- نقش‌های مجاز برنامه `super_admin` و `user` هستند. دسترسی مدیریتی از Admin Plugin و کنترل دسترسی سفارشی Better Auth می‌آید.
- نشست‌ها در دیتابیس ذخیره می‌شوند، عمر پیش‌فرض ۷ روز دارند و خروج از حساب از طریق Better Auth انجام می‌شود.
- مدیر کل می‌تواند از نوار بالای پنل حساب کاربر بسازد؛ کاربر عادی به endpointهای مدیریتی دسترسی ندارد.

### ایجاد اولین مدیر کل

پس از نصب وابستگی‌ها و تنظیم متغیرهای سروری `DATABASE_URL`, `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL` و `APP_URL`، از محیط امن و مورد اعتماد اجرا شود:

```bash
npx auth@latest create-admin --config ./src/lib/auth.ts --email admin@example.com --name "مدیر کل" --role super_admin
```

CLI برای رمز عبور prompt می‌دهد؛ رمز را در Git، چت یا فایل‌های پروژه قرار ندهید. این دستور را فقط یک‌بار برای حساب مدیر کل اولیه اجرا کنید.

Migration افزونه مدیریت در `db/migrations/0003_better_auth_admin_plugin.sql` قرار دارد.
